# Port & Shipping Logistics Management System

A system for managing vessel arrivals, berth allocation, container yard tracking,
crane scheduling, gate dispatch, and customs clearance at a port — with a real-time
operations dashboard.

## Structure
- `backend/` — Node.js/Express API, core scheduling & logistics services
- `frontend/` — React dashboard and operational views
- `database/` — SQL migrations and seed data
- `docs/` — architecture and API documentation
- `scripts/` — setup and utility scripts

## Getting Started
1. `cp backend/.env.example backend/.env`
2. `docker-compose up`
3. Backend: http://localhost:4000
4. Frontend: http://localhost:5173
